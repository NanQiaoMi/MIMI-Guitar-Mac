# 字体来源与许可说明

## Fraunces 与 Inter

字体子集来自原站 `@fontsource/fraunces`、`@fontsource/inter` 包。对应完整 SIL Open Font License 1.1 文本见 `OFL-Fraunces.txt` 与 `OFL-Inter.txt`。

## Bravura

原站播放器字体来自 `public/font/Bravura.*`。独立许可证全文见 `OFL-Bravura.txt`；字体文件中的版权行保留 Steinberg Media Technologies GmbH 的署名及保留字体名称。

## Cascadia Code

原站播放器字体来自 `public/font/CascadiaCode.*`。独立许可证全文见 `OFL-CascadiaCode.txt`。许可证来源为 Microsoft 的 Cascadia Code 官方仓库。
