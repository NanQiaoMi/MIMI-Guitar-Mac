# 原站视觉与交互规格

2026-10-24。对照来源：本机真实网页和当前源码；不是重新设计。主代理已在 IAB 以 1280×720 CSS 视口逐段查看首页、三种曲库布局、命令面板和和弦提示。Shell/Player 分别捕获其余页面和播放器/工坊。原生窗口应按内容区域与相同状态比较；系统标题栏与交通灯单独计量。

## 1. 全局

- 网页 `html` 根字号为 `clamp(14px, 0.84rem + 0.35vw, 17.5px)`；1280视口实际17.5px。不能把所有内容缩成默认13px原生列表。
- Body 底色 `#fbfaf7`（base `#fbfaf6`），纸纹来自原64×64 fractal-noise SVG和渐变。复用实际源数据；不随意换成普通纯灰底。
- 标题：Fraunces / 系统中文 PingFang SC 等；UI：Inter / 系统；正文 serif：Noto Serif SC / Source Han Serif SC / Songti SC / STSong / Georgia；mono：Cascadia Mono / Cascadia Code。源依赖有 @fontsource/fraunces 400/500、inter 400/500/600/700。使用可注册的真实本地字体与原回退链；打包许可证。
- 首页特定色：文字 `#2d2926`，棕 `#705c42/#5c4a38`，次级 `#8c7b68`，暖金 `#c49a45/#8f6d2b`，陶土橙 `#c84b31`，暖边 `#e2d8c3/#e0d6c0`，浅纸 `#fbf9f4/#faf6ee`。个人资料页还使用原蓝灰/深绿动作色，不能统一替换为一种橙色。
- 原圆角阶梯与具体覆盖类要分别保留：全局卡24、按钮18、inner10、small6；首页rounded-3xl在1280根字号下约26.25；导航与分段组为胶囊。
- focus-visible 2px `#41a1cf`、offset2；hover、selected、disabled和加载状态不能混为同一外观。
- 原内容 max1240。1280视口导航 x20,w1240；首页/曲库内部 x46.25,w1187.5。源码 sm:px6 对应26.25实际像素。小窗口按原断点改列数与换行，不裁掉控件。

### 首页交互

- Hero随机精选来源为源 `MASTERPIECE_COLLECTION`，不是只随机改标题。试听为原地播放/暂停，准备与播放错误是独立状态；离开或另一个声源夺焦时同步状态。
- 已收录和弦弹层为深褐小卡、金标题、白底真实指法图，锚点紧邻按钮；点击固定、Esc/外点关闭，切曲/换布局关闭旧锚点。
- 源Eb等未收录和弦显示“暂未收录此和弦指法图”，保持该状态，不虚构图形。
- Bento混排/纯六线/数字谱切换改变示例；三轨MUTE改变各轨状态；指板保留弦名、金银不同弦线、品柱/镶点、红橙选中品位和点击高亮。
- 今日/周/月使用原真实数据规则（playable scoreUrl非空，按publishDate筛，少于6回落全热度前10），不把三套硬编码示例冒作实时榜。
- 滚动/hover/入场动画在Reduce Motion下保留可用静态状态，不因关闭动效丢内容。

## 4. 曲库的三种布局

顶部筛选纸卡：类别“全部典藏/吉他谱/尤克里里”；右侧搜索+“画廊/列表/展卷”。横线后依次难度、谱型、曲风、调性，再调弦和排序。全部筛选/切换和窗口换行都须保留。

- 难度：全部/零基础/初级/中级/高级/专业。
- 谱型：全部/弹唱/指弹/和弦/六线；sheetForm4包含7。
- 曲风101/102/103/105/107/109，调性、调弦选项照源 `tabQuery.ts`；排序研习热度/最新上传/演奏难度。
- 结果计数下方内容，右侧原谱试听时长下拉；精确选项取 `scorePreviewDuration.ts`。加载原谱/音源的准备时间不计试听时长。
- 90项/页，真实页码与上下页/边界；过滤/类别改变回第一页且保留适用查询。

**画廊**：1280宽为两列大横卡；左真实screenshotUrl缩略图和圆形试听，右曲名/作者、三个真实调性参考和弦、底部分隔线与调性/谱型/难度标记，热度位右上。宽度变更时按原layoutCols处理。

**列表**：完整表头“试听、曲目/歌手、调性、谱型、难度、研习热度、操作”；每行有试听、标题/副文、各标记、心形收藏和深色研习按钮，hover/焦点/播放样式明确。

**展卷**：1280宽三列纸册卡，左侧纸页侧脊、FOLIO编号/热度、曲名作者调性、真实截图、叠放试听按钮、底部难度与“开启全屏原谱”。不能把同一画廊重复三列冒作第三模式。

图像来自随包 `storage`，包含真实摄影/谱图；不替换为通用封面。ImageIO异步降采样到实际展示像素、受限缓存、过期任务取消，避免90张原图全部全尺寸解码。

## 5. 命令面板

1280视口居中约x272,y87,w736，空查询面板高约590，空结果约342；背景全屏半透明灰/模糊。圆角约30，浅纸。

顶部长搜索框（原focus蓝描边），放大镜、可用清空按钮和圆形关闭；类别胶囊全部/吉他/尤克里里。空查询展示完整快捷动作（包含纸质书卷开卷、热门、指弹、尤克里里、交互体验等）及最近项。搜索结果有选中浅蓝灰描边、左图标、标题/类别、作者、难度/谱型/调性/热度。结果总数独立显示。

加载时输入旁旋转状态，内容“正在搜索曲库…”；无直接结果时明确显示完成空状态和“在全站检索”入口。底部保留上下导航/回车打开/Tab焦点/Esc关闭提示。CmdK再次关闭，打开自动聚焦，键盘选中项可见；关闭恢复触发控件焦点。
