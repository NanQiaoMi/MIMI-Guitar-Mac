# 页面导航速度与切换动效优化计划

日期：2026-10-19。基线 `master@939cf5f7`，分支 `feature/fast-page-navigation`。

## 目标与约束

用户反馈页面间导航需要长时间加载。本轮先测量真实等待，再减少重复服务器工作与不必要的资源加载，为成功导航增加短促、连贯的过渡。点击后立即有反馈，但不能以延长退场、假进度或遮挡旧页面掩盖真实加载。

- 保留个人本地资料、备注冲突与离页保护、工坊工程、播放回执和既有 full/gentle/off 偏好；系统减少动态优先生效。
- 不把在线目录不可用伪装为就绪；不连接用户真实数据库、不改容器/卷/迁移，不输出凭据。
- 原 `D:\MIMIguitarweb` 的402行状态与1023文件保护清单保留。只在隔离工作树实施，最后本地提交并 `--no-ff` 合入干净master，不推送或部署。
- 使用三名既有 `gpt-6-luna / max` 子代理，先只读审查，确定契约和独占写范围后再实施。

## 分工与阶段

1. **基线测量**：主代理记录每条主要路由两次HTTP耗时、状态和字节数；独立浏览器标签测实际点击、文档请求、资源加载和就绪状态。不导航、刷新或编辑用户当前4336标签。
2. **并行审计**：集合代理分析SSR/目录/数据库等待；动效代理分析Base与导航过渡、预取、偏好；播放器代理分析SPA/跨文档的卸载、音频、脚本和离页保护风险。所有方案须依据实际Astro 5.18.2包和官方文档。
3. **冻结方案**：依据测量在Astro ClientRouter与浏览器跨文档过渡中选择最小可靠实现。明确路由范围、失败/取消/历史行为、脚本初始化、生命周期及文件写所有权；不直接全站替换成SPA。
4. **实施**：服务端减少可证实重复工作，并限定失效/恢复语义；导航反馈不阻止原生操作，预取尊重节流和连接条件；过渡仅在内容准备好后发生，动画不阻塞功能，低动态保持可用。
5. **验证**：行为测试覆盖合并请求、失败恢复、过期结果、取消/重复点击、监听清理和偏好；候选 `npm test` → `npm run build` → `npm run typecheck`。真实浏览器验证菜单/搜索、列表筛选、前进后退、输入草稿、工坊及播放离页边界。检查320/390/768/1366视口和三种动效偏好。
6. **交付**：前后耗时在同样数据库不可用条件和独立端口比较，区分冷/热、HTTP和浏览器就绪。更新证据与DEV_LOG，提交、合并、实际master回归、重启4336并核验health/readiness/音源，复核原树保护和清理临时标签/模拟。

## 必须处理的边界

| 场景 | 预期 |
| --- | --- |
| 数据库暂时不可达 | 有界等待、真实demo/unavailable；并发请求不重复拖长导航，恢复可以再探测 |
| 多次点击/历史导航 | 最后一次合法导航生效；不残留遮罩、滚动锁、重复监听或旧页面动画 |
| Ctrl/Cmd点击、下载、外链、锚点、表单 | 保留浏览器语义；不预取写操作，不拦截不适用的链接 |
| 未保存备注与工坊草稿 | 不绕过原生离页提示/保存机制，不把旧草稿带入别的工程或会话 |
| 播放时离开 | 旧引擎/worker/listener按既有约定清理，不出现重复声音或跨页面残留 |
| 网络失败/无动画支持/禁用JS | 原生导航仍可用；不把旧内容先淡出成空白，功能无需等待装饰动画 |
| 低动态/系统reduce | 动画减弱或关闭，保留必要位置与交互；偏好不因导航闪回full |
| 预取与缓存 | 不跨用户缓存认证HTML，不缓存写请求；数量/时效有界，尊重Save-Data及慢连接 |

## 完成依据

以同条件前后测量和公开DOM/网络证据说明真正改善，不承诺恒定60/120fps。真实Safari/Android触摸、长期播放、生产数据库不可用时标记未执行。源码或新增测试/类型失败均不得合并；57条Svelte既有警告和41条Astro hints作为基线，不扩大。

## 审计后范围与结果

基线测得本地页 `/practice`、`/library`、`/motion`、`/studio` 热请求约3–13ms；在线首页/吉他谱/尤克里里/专栏连续两轮均约2秒。独立浏览器练习→吉他谱的文档响应头耗时2053.9ms，点击至可操作列表约3113ms（包含自动化与水合耗时）。测试基线383项，376通过，7项数据库测试跳过。

### 已冻结实施方案与写所有权

- **集合代理**：独占 `src/lib/catalogReadGate.*`、公开目录/文章查询页面、`src/lib/tabQuery.ts`、`src/pages/api/search.ts` 及相应测试。仅对已识别连接失败作短暂退避，探测请求合并，不缓存查询结果；认证、写操作、readiness、Prisma配置均不纳入。冷启动和退避到期允许一次真实探测等待，成功后恢复真实查询。首页/搜索独立读并行，共用首页全榜回退；错误回退必须继续标记demo/unavailable，文章不可用与404区分。
- **动效代理**：独占 `src/layouts/Base.astro`、`astro.config.mjs`、`src/styles/motion.css`、新增导航策略/运行时及测试。保持MPA与原生跨文档View Transition；只为少量无副作用页面添加意图预取，缓存短暂且私有，认证响应不缓存。导航反馈不阻止默认导航、不提前隐藏旧内容；原生取消/失败/历史恢复不得残留忙碌状态。保留full/gentle/off和系统reduce。
- **播放器代理**：独占试听引擎的轻门面/按需实现、播放器pagehide清理、工坊保存离页边界及相应测试。不改其它页面或布局。取消300ms无条件音源预热；首次试听才加载AlphaTab/解码器，快速切换、取消、暂停不得迟到开播。普通谱面pagehide暂停但不禁止后台听歌；工坊有待存或保存失败时保留原生离页提示，保存成功解除。
- **主代理**：整合审查、文档与证据、HTTP/浏览器验收、提交/合并/master回归。只在子代理完成后修正其拥有文件，避免交叉覆盖。

不接入ClientRouter：现有备注离页保护依赖beforeunload，Svelte和音频生命周期按文档初始化；跨文档动画已经存在。将整站改成SPA会扩大此次修复范围，并使已验证的保护失效。原生过渡在新内容准备好后播放，不增加人为等待。断网冷请求的真实连接等待仍需如实记录。
