# 全站交互与创意动效迭代计划

日期：2026-10-18 至 2026-10-19；证据目录沿用起始日期 `expressive-motion-2026-10-18`。基线：master `61f76234`；工作分支：`feature/expressive-motion-experience`。

## 目标与边界

让找谱、整理个人谱、打开工坊工具和日常练习拥有统一而有辨识度的反馈。沿用温暖纸张、墨色和声学意象；把创意放在纸页层次、选中底片和短促的展开反馈中。业务状态立即改变，动画呈现变化，不用动画排队等待保存、导航或音频命令。

新增实用功能：可保存的全站动画偏好，以及可以实际操作、即时比较效果的体验入口。默认跟随系统；提供轻柔、静止两种手动选择。系统“减少动态效果”优先。设置只保存在当前浏览器，存储失败时明确提示仍可本页使用，不承诺包含在个人资料备份中。

本轮保持 Astro 多文档导航、现有播放器生命周期和练习恢复协议。不得引入客户端路由、跨页持续播放承诺、为动画重建播放器、延迟按钮业务动作或伪造下载进度。已有曲库不可用/演示提示必须保留。真机、可闻性和持续帧率需要独立证据。

## 设计规则

| 场景 | 反馈 | 约束 |
| --- | --- | --- |
| 全站导航 | 保留原生跨文档渐隐/轻移、固定页头 | 直接导航，不等转场；不支持的浏览器正常跳转 |
| 卡片/结果 | 有界纸页入场、短距离重排、静态阴影层次 | 入场总预算不超过 280ms；不把服务端筛选伪装为客户端全量筛选 |
| 工具/菜单 | 同一曲线展开、单一选中底片、命令即时执行 | 不动谱面/音符光标，不以高度动画驱动 AlphaTab 重渲染 |
| 状态/完成 | 短促墨点或纸签反馈，真实数量/阶段 | 错误不能只用颜色；不得虚构百分比或下载完成 |
| 首页/背景 | 有限幅度纸层、声学意象 | coarse pointer 无视差；隐藏/离屏停止装饰 RAF；静止不启动装饰运动 |
| 轻柔/静止 | 轻柔以短淡入为主；静止直接到终态 | 系统 reduce 优先；运行中切换立即落定，界面不残留半透明 |

使用共享 120/200/260/280ms 节奏，特殊纸页保留 360ms。避免 `transition: all`、常驻 will-change、大面积滤镜动画、重复监听和逐帧 React/Svelte 状态更新。主要交互目标至少 44 CSS px；键盘和触摸与鼠标同等可用。

## 必查边界

- **偏好**：SSR 无 window、非法/旧存储值、读写拒绝、跨标签页事件、系统运行中变化、关闭后立即重开、卸载清理。首屏在组件 hydration 前应用偏好，避免先运动再关闭。
- **列表/筛选**：稳定键、空列表、错误与演示状态、筛选后焦点、快速切视图、归档/恢复/排序与真实持久化、原生 query/history/new-tab 语义。列表动画不扩大数据事务范围。
- **工坊**：菜单外点/Escape/焦点归还、抽屉折叠隐藏焦点、弹层互斥、快捷键隔离、歌词草稿目标、导入/载入/删除忙碌与过期结果。只有明确的工程提交动作才能停播或替换工程。
- **备份**：只表达真实准备/校验/下载发起状态，保持取消、revision/CAS、staging 和 Object URL 清理；下载发起不能写成文件已保存。
- **音频与性能**：工具开关前后同一谱面、播放器和播放位置继续；动画订阅不能注册到音符/谱面业务动画。隐藏后无装饰循环，返回不自动播放；清理帧、定时器与事件监听。

## 实际实现与验收记录

三名 `gpt-6-luna / max` 子代理按独占范围实施，并交叉审查；实现与验收详见 [本轮证据](evidence/expressive-motion-2026-10-18/README.md)。

实际新增全站动画偏好、工坊快捷键搜索/分类；曲库、个人谱、备份、首页及设计展厅接入同一偏好。保留已存在的工坊弹层/事务护栏，不把它们重复记为新功能。偏好降级只结束 wrapper 自身动画，不重挂播放器；首屏已可见内容不重播揭页、键盘焦点会让入场落定。两个首页区块改为 idle hydration，在滚到之前安装观察器，缺能力时保持静态内容。

浏览器发现并修复的追加问题：最新上传 `sort=0` 被错误当作清空参数；320px 工具栏的两个操作组需要换行；备注冲突后的无效重试；Mac 快捷键组合搜索的前缀误匹配。最终工坊 320px 复测为 `clientWidth=305`、`scrollWidth=305`、`openDialogs=0`（`studio-320-final-toolbar`）；旧约 1px 差值来自修复前的 `studio-320-settled` 记录。旧设计展厅独立粒子、追光、倾斜、磁吸和短计数也补齐偏好/清理边界，避免新设置只在主页面有效。

实际采样看到完整模式体验底片有连续中间 transform，轻柔/静止只有各自终值；有约 50ms 的帧间隔，不能据此宣称恒定帧率。十六小节自写谱切工作台、调音台和帮助后仍在播放、游标推进，公开谱面节点保持；两小节首次自然结束未计作连续性通过。两标签偏好同步、备注冲突保留/取消有浏览器记录；队列第二项上移后重载保序由人工 UI 观察确认，结构化 JSON 只记录单次顺序，不独立证明重载前后差异。分卷验收仅证明可以再次发起当前文件下载，不能确认设备保存或大容量恢复。

设备与运行门槛仍独立保留：iPhone/iPad Safari、Android 真机、虚拟键盘、屏幕阅读器、200% 系统字号、可闻性、2 小时/30 分钟播放、生产联网曲库和 1 GiB 备份未执行。原生离页确认窗未由浏览器桥暴露，不把页面保留现象冒充系统弹窗验收。
