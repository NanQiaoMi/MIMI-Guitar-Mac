## 交付目标

提供可以从 Windows 带到 Apple Silicon 或 Intel Mac 的本地开发包，包含可追溯稳定源码、既有全部开发计划与证据、当前接续优先级、Mac 环境与数据恢复步骤、资源清单和校验工具。项目安装依赖仍需 npm 与 Docker 官方镜像访问；不把带媒体的完整包称为无需网络安装的离线开发环境。

## 保护与版本边界

1. 原 `D:\MIMIguitarweb` 保留原分支与全部未提交内容；不在那里安装、构建、清理或提交。稳定源码以已验收的 `master@c0fdccae` 为起点；迁移增量独立分支提交和 no-ff 合并。
2. 原工作区未合并内容不得冒充稳定版本；另行只读列清单、保存可恢复的代码候选快照/差异，并说明不能自动覆盖稳定源码。禁止遗漏已知未提交代码而声称已完整带走全部开发内容。
3. 不打包真实 `.env`、账号/云端令牌、SSH/签名私钥、Cookie、机器配置、Docker 虚拟磁盘、依赖缓存或 Windows 构建产物。不输出凭据。源码与 Git 历史分别检查是否包含敏感信息；历史不满足可分发边界时，不将未经检查的历史装入包。
4. 备份现存数据库只读执行。默认携带曲库与文章、迁移记录及必要 schema；账号、口令哈希、服务端收藏与上传操作记录不混入开发曲库。浏览器 IndexedDB 中的个人工程、附件、待练、收藏、练习历史与断点，需要应用内完整备份及跨 origin 恢复，不能用 PostgreSQL dump 替代。

- gpt-6-luna/max 代理 A：只读核对代码与全部计划/证据，编写 Mac 接续开发文档，区分已实现/Windows 已验收/Mac 待验收/尚未实现，形成带优先级、文件入口、边界、测试与完成条件的后续任务表。独占 `docs/mac-development-handoff.md` 与 `docs/mac-next-development-backlog.md`。
- gpt-6-luna/max 代理 B：审查当前 macOS 安装和本地启动障碍，维护专用迁移 Compose 模板、Mac 安装/数据库导入脚本和有限行为测试。独占新 `tools/mac-*`、`tools/lib/mac-*`、`tests/mac-*` 及 `docker-compose.mac.yml`；不改既有音频/业务代码或机器配置。
- 主代理整合后对 Mac 脚本做静态/模拟依赖验证；有本地 PostgreSQL 可用时使用独立临时容器恢复，不对现存曲库执行迁移或写入。Mac 真机运行不能由 Windows 检查代替。

## 包结构与操作边界

1. 顶层 `START-HERE.md`、版本说明、开发计划索引、校验文件和恢复说明。
2. `project/` 提供稳定源码与锁文件、Prisma schema/迁移、必要静态资源、文档和测试；Mac 必须重新 `npm ci`、生成 Prisma Client、构建。Node 版本遵从现有 engines 的 24.x。
3. `database/` 提供 PostgreSQL 16 的可移植 custom dump、非敏感计数/版本清单与恢复验证结果。恢复脚本只面向新建且由迁移工具创建的独立数据库；已存在数据库绝不清空、覆盖或执行 `--clean`。
4. `project/public/storage/` 携带完整、已盘点的本地曲谱、图片和专用音源；标准 GM SoundFont 来自已跟踪源码并保留许可。清单逐文件记录相对路径、字节数、SHA-256；处理缺失、链接和损坏时明确报错。
5. `preserved-work/` 明确存放原工作区未合并内容及恢复说明，若敏感扫描阻断则只保存不含凭据的候选文件并逐项列明排除原因。不能将未知脚本作为 Mac 默认执行入口。
6. 大体积媒体以可被 macOS Archive Utility / bsdtar 处理的 ZIP64 或 tar.gz 封装；跨平台路径必须相对、无盘符/绝对路径/逃逸项，无 NTFS junction。包内校验与压缩包外 SHA-256 均验证。至少检查解压清单、CRC/流完整性、源码与媒体数量/摘要、数据库可恢复性。

## 失败与交付规则

- Docker 不可用时，继续源码/文档/媒体的独立工作，记录真实数据库快照为缺失；不拿过期 dump 冒充当前快照，不恢复/重置 Docker 数据目录或曲库。
- 当前曲库资源引用与本地文件的对应关系要有覆盖证据；只抽样 readiness 不等于完整媒体迁移。
- 如空间不足或用户选择精简包，保留可扩展的媒体分包与清楚依赖关系，不静默丢文件。包内不包含本机 node_modules、dist、.astro 和实际 `.env`。
- 原目录保护、匹配单测、必要构建/类型检查、文档/脚本验证、压缩包内容与 SHA-256、数据库隔离恢复结果和 Mac 未执行项分别记录。确认通过后本地提交并 no-ff 合并稳定分支，不推送、发布或上传。
