## 边界与风险控制

| 情况 | 处理要求 |
| --- | --- |
| 原谱或截图本身在本地不存在 | 报具体资源缺失；不伪造成功、不抓取未知远程源 |
| 目标已有不同文件 | 准备前失败并保留原文件；不批量覆盖或以大小相同代替内容一致 |
| 源/目标重合、祖先嵌套、junction/symlink逃逸 | 拒绝；实际写入必须在已验证目标内 |
| 资源数量较大 | 有界并发、本地增量复制；不把下载缓存/媒体提交Git，不在服务启动时扫描全部历史文件 |
| 新构建重新生成dist | 由public副本构建并重新检查dist；不只临时补dist而遗漏下一次构建 |
| HTTP200却返回HTML错误页 | 当作错误响应/部署问题，避免误报IBE解码损坏 |
| 浏览器暂存旧404 | 明确重试绕过失败缓存，仍保持服务器真实错误与下载边界 |
| 数据库依旧不可用 | 目录回退明示；readiness维持503，不因演示谱修复改成ready |
| 音频/设备证据 | 分别记录渲染、播放状态、资源加载和真实听感；未做真机不能写通过 |
