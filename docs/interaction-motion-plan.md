## 1. 目标、基线与范围

稳定基线为 master `3345821d`。本轮工作分支 `feature/interaction-motion-system`，复用隔离工作树，不在原 D:\MIMIguitarweb 开发。原树本轮重新记录 1024 份文件 SHA-256、402 行 Git 状态；这些是保护清单，不沿用上轮统计。

“接近苹果”在此指有目的的运动、清楚的空间关系、简短精确的反馈、可以中断的操作，以及减少动态效果支持。数值是本项目的设计选择，不是 Apple 官方参数，也不代表对 Apple 系统效果的一比一复刻。

参考：[Apple HIG Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[WebKit 跨文档转场](https://webkit.org/blog/16967/two-lines-of-cross-document-view-transitions-code-you-can-use-on-every-website-today/)、[MDN View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API/Using)。

## 2. 动效语言与约束

| 场景 | 目标时长 | 运动与反馈 | 约束 |
| --- | --- | --- | --- |
| 按下/松开 | 100–140ms | 轻微收缩、色阶反馈 | 按下即执行原命令；无等待、无高频装饰 |
| 分段选择 | 180–220ms | 单个选中底片连续移动 | 标签不跳动；方向键、Home/End；44px 目标 |
| 小菜单 | 180–240ms；退出更短 | 从触发源附近淡入、6–10px 位移 | 快速反转不排队；Escape/外点关闭；焦点返回 |
| 搜索弹层 | 240–280ms；退出 140–180ms | 独立背景遮罩、面板 10–14px 位移、轻微缩放 | 原生 modal 焦点边界；关闭期间不可误触背景 |
| 音轨/音色工具 | 220–260ms | 局部展开与淡入 | 不重建播放器、谱面或音频；不动画整个阅读区域 |
| 片段编辑/状态 | 160–220ms | 新内容短距离进入；状态文字即刻更新 | 不同时保留两个可编辑表单；错误与草稿不丢失 |
| 跨页面 | 240–300ms | 稳定页头、内容轻淡变换 | 原生导航；不为转场延迟网络请求或拦截链接 |
| 减少动态效果 | 0ms 或极短非位移反馈 | 无平移、缩放、平滑滚动 | 信息、选中态、错误和操作能力完整保留 |

统一 duration/easing/distance token，优先 transform/opacity。禁止新引入 `transition: all`、全屏模糊动画、常驻 `will-change`、装饰性常驻 RAF 和人为 setTimeout 业务延迟。仅特定小工具允许短暂尺寸变化，不把大谱面高度动画化。可中断的 CSS/Svelte 过渡应由当前状态决定终点；异步完成回调必须有代次保护。

## 3. 导航与生命周期边界

项目当前是 Astro 多文档页面。使用原生跨文档 View Transitions 的渐进增强，不引入 ClientRouter，也不迁移岛组件生命周期。浏览器不支持时正常导航；刷新、外链、下载、修饰键新标签、表单提交和 hash 链接仍由浏览器处理。

页头单独命名且不进行位置形变，正文以小幅淡入/淡出衔接。只给唯一布局元素命名，避免重复 view-transition-name。首次访问不人为延迟显示，不追求大幅页面滑动，不猜测导航历史方向。减少动态效果时关闭跨文档动画。

现有离页保存、beforeunload 提示、音频释放、页面后退/前进和滚动恢复必须保持。跨页仍按现有生命周期暂停/卸载播放器；本轮不承诺跨文档持续播放。组件内切换工具必须保留同一个播放器、当前谱、位置、音轨与练习会话。浏览器实际验收需覆盖往返导航和有草稿的离页路径。

## 4. 控件与可访问性

1. 快捷搜索：统一弹层入场/退出；使用原生 dialog 管理 modal 焦点边界，打开聚焦输入，Escape 和可见关闭按钮可用，关闭返回触发元素。Tab 正常循环焦点，分类支持方向键。修复 input 与父容器重复处理同一键盘事件。滚动锁恢复打开前状态；窄屏与虚拟键盘使用动态视口和有界内部滚动。保留取消搜索、请求代次、错误/重试与离线提示。
2. 移动导航：触发器有准确展开状态、关联面板与可见关闭反馈；面板短距离入退，支持外点、Escape、移出焦点关闭。采用普通导航链接语义，避免半实现的 ARIA menu。小屏菜单高度受视口约束，所有主要目标 ≥44 CSS px。
3. 分段控件：复用单个底片，选中状态同时有语义和视觉；键盘不被页面快捷键重复消费；快速反复选择不出现旧内容覆盖。初始状态、空/禁用选项、减少动态、320px 布局均有定义。
4. 播放器：音轨/音色工具的出现与收起使用统一过渡及 aria-controls。控件更新即执行原有音频命令；不动画音符光标、不重载 AlphaTab。关闭的工具不可保留可聚焦的幽灵控件。
5. 练习片段：编辑区进入、删除确认与通知有克制反馈；同一片段编辑失败保留输入；过期版本的应用按钮必须明显禁用；异步保存/应用/删除期间维持现有防重入与 CAS。键盘 Enter/Escape 行为不得因动画变化。

阶段 A：三名 `gpt-6-luna / max` 子代理分别只读审查导航生命周期、控件/焦点、动效系统/性能。主代理确认接口、保存保护清单、建立分支和本计划。

阶段 B：共享 motion helper、分段控件与领域测试由系统代理独占。弹层、CommandPalette、MobileMenu 由控件代理独占。ScorePlayer 工具与 PracticeFragmentLibrary 由第三代理独占。主代理负责 Base.astro、独立 motion.css、可交互验收页面、文档和集成。代理不操作 Git、服务、依赖、浏览器或其他写所有者文件。实施前冻结共享接口，避免互相覆盖。

阶段 C：主代理检查所有改动，代理交叉复核生命周期和键盘行为；修复发现的问题后运行单元/类型/构建。构建使用独立依赖副本；不通过原树 node_modules 联接安装或改写依赖。

阶段 D：独立本地端口实际浏览器验收，保存截图和运行时记录。仅提交可追溯源码、文档与精简证据；不提交个人备份、机器配置、依赖、构建产物或凭据。

验收工具补充：截图有约数秒取样延迟，不能证明 200ms 动画的中间帧；浏览器只读桥也不暴露完整动画 API。因此增加独立 `tools/motion-frame-probe.html` 测试夹具，仅在本地构建副本临时提供，通过同源 iframe 的真实点击/键盘事件只读采样 transform/opacity 与 RAF 时间，将结果呈现在可见测试面板。它不调用隐藏播放器 API、不改应用 DOM/数据、不写入正常产品页面；样本仅说明该浏览器测试条件，不能推出所有设备恒定帧率。

阶段 E：完成特性分支提交，在干净 master 工作树 `git merge --no-ff`，执行主分支回归；重新核对原树文件与状态保护清单。不推送、不部署。

## 7. 后续迭代顺序

P1（本轮）：动效基础、全站导航、搜索/移动菜单、分段控件、播放器工具与片段编辑的关键路径，带可交互预览和真实浏览器记录。

审查追加 P1：现有首页纸页翻页用固定 500ms 定时锁；系统减少动态虽然关闭动画，按钮仍等满 500ms，且卸载不清定时器。共享系统完成后，由同一系统代理独占 PaperFolioSection.svelte 及独立必要控制器/测试进行最小修复：转场结束即解锁、reduce/页面隐藏时落定、卸载清理、分页目标 44px、移除常驻 will-change。保留现有纸张布局、曲谱链接和音频行为；不把旧 FOLIO_MOTION_PLAN 中尚未实现的效果当作当前能力。

接线复核更正：上述 `PaperFolioSection` 属于历史首页组件；当前首页 `index.astro` 已使用 `home/HeroShowcase` / `MasterpieceStage`，没有挂载此组件。因此本轮不宣称这些修复改变了当前首页。修复后的纸页在 `/motion` 新增独立示例区，明确使用内置演示数据，以实际界面验收翻页锁、减少动态和 44px 页码。现首页布局不改动。

P2（后续独立增量）：在同一 tokens 下扩展曲库筛选/排序、工坊侧栏和快捷工具、备份进度与完成状态；先验证操作收益，再动复杂谱面布局。备份或导入的真实进度不能由装饰动画伪造。

P3（设备与性能验收）：iPhone/iPad Safari 和 Android 真机，低性能设备、200% 字号/缩放、虚拟键盘和系统中断，桌面 2 小时/移动端 30 分钟播放。根据实际帧时与电量记录调整效果强度；未完成前不声称全设备稳定。

## 8. 本轮实现与特性分支验收记录

- `src/lib/ui/motion.ts`：CSS/Svelte 共用 tokens、SSR 安全过渡、单共享媒体偏好监听；只结束登记 wrapper 自身的动画，最后一个 wrapper 销毁时拆除监听。`folioMotion.ts` 单独拥有翻页锁、代次与有界兜底定时器。

### 计划调整与修复

双向 Svelte 过渡采用同一个可反转配置：完整 panel 入退为 260ms，menu 为 200ms；中途反转按当前进度完成。独立 out-only helper 使用 exit 160ms。这样避免为缩短退出而丢失反转连续性，与第 2 节的“退出更短”目标有此明确取舍。

实际浏览器及交叉审查发现并修复：关闭 dialog 的样式误覆盖原生隐藏；backdrop-filter 祖先导致 fixed 菜单定位偏移；Svelte 暂停退出分支后 inert 不更新；菜单链接被卸载导致搜索返回焦点丢失；作用域 CSS 覆盖消费者的弹层最大尺寸；纸页底层覆盖普通流分页导致按钮可点击但不可见。后两项依靠真实尺寸/截图发现，不能由单测或编译代替。
